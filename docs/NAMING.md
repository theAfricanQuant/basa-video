# Basa naming record

Status: preliminary collision screen, 22 August 2026. This is not a formal
trademark clearance or legal opinion.

## Intended hierarchy

- Brand: **Basa**
- Current product: **Basa Video**
- npm package and executable: `basa-video`

The name was selected for its Berom meaning, “teach,” and not to imply an
affiliation with another organization.

## Preliminary checks

At the date above, both `basa` and `basa-video` returned “not found” from
the npm registry, and no exact `basa-video` repository collision appeared in
a GitHub name search. General web results showed unrelated uses of “BASA,” so
these checks do not establish exclusive rights or registration availability.

Before a public commercial launch, search confusingly similar marks—not only
exact matches—in the intended countries and relevant software, education and
hosted-service classes. Repeat the npm, source-hosting and domain checks when
the release name is finalized.
